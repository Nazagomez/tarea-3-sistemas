Books Example Site

This site demonstrates a microservices architecture composed in the browser: books, authors, publishers and reviews are independent mini-sites, each talking to its own backend.

Published mini-sites:

  • Books (Vue 3)
  • Authors (React)
  • Publishers (vanilla JavaScript)
  • Reviews (Vue 3)

Backends:

  • Books API: Netlify Functions + Neon (PostgreSQL)
  • Authors API: Cloudflare Workers + D1
  • Publishers API: Vercel Functions + Turso
  • Reviews API: Cloudflare Workers + D1
